# imperative
Imperative programming in Agda supporting efficient execution via ST and
separation-logic style verification.

The library proper is in `src`. Examples showing how to use the library are in
`example`. Issue `make` to compile the project to an executable `example/Main`.
Issue `make html` to render the literate Agda exposition to HTML (in `html/`).

The module `Imperative` is the entrypoint to the library. The root of the
exposition is the module `Exposition`.
