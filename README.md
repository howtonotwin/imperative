# imperative
Imperative programming in Agda supporting efficient execution via ST and
separation-logic style verification.

Library proper is in `src`. Examples showing how to use the library are in
`example`. Issue `make` to compile the project to an executable `example/Main`.
Issue `make html` to render the project as literate Agda to HTML (under
`html/`).

The module `Imperative` is the entrypoint to the library and is also the root of
the exposition.
